Part 2 - Web Accessibility

When we uploaded our redesigned website to Neo cities and tested it with the WAVE Web Accessibility Evaluation Tool, we found fewer issues than expected. The main category of problems detected across our pages were contrast accessibility issues. Specifically, some text such as the “All rights reserved” footer text was too light against a white background, which caused insufficient contrast for users with low vision or color‑perception difficulties. 
To address this, we made generalized improvements to color contrast across the entire site. Instead of fixing only one instance, we reviewed all pages for areas where text or UI elements used very light colors. We then adjusted these colors to meet accessibility contrast guidelines, ensuring consistent readability. In the footer specifically, we changed the muted, low‑contrast text color to a darker value, specifically black so it would stand out properly against the white background. Overall, the types of changes we made focused on improving accessibility, legibility, and consistency, based on feedback from the WAVE evaluation. These adjustments help ensure that the website is easier for all users to read and navigate.
